# Runtime core audit (backend/app + session_runtime/supervisor)

## Summary
1. ruff clean; mypy clean (54 files). 71 publication/evidence/routing tests pass, but they miss the gaps below.
2. Publication validator is the strongest control, yet it has two reproduced bypasses: numbers with unit suffixes (`12bn`, `5x`, `20bps`, `3Cr`) pass the unbound-number check, and fact IDs omit the instrument so multi-ticker runs overwrite each other.
3. Freeform answers (any non-report, non-single-tool query) have no grounding validation at all; output safety review runs after text is already streamed.
4. Reliability: blocking sync provider calls in the event loop with no per-tool timeout, circuit breaker never trips on transport errors, context compaction orphans tool_calls, Codex ignores max_tokens/temperature/timeouts.
5. Security: secret redaction is key-exact and misses common keys; Codex credential file is created before chmod; Jev outage fail-open by design.

## Score: 6/10
Good: bounded loop, typed events, fail-closed fallbacks for reports/lookups, safe YAML/prompt rendering, skill path checks, owner-only trace files, supervisor guarantees a terminal event. Deductions: grounding bypasses (P1), freeform path ungrounded, event-loop blocking and missing tool timeouts, breaker/compaction bugs, weak redaction.
