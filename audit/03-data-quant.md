# 03 - Data and Quant Layer Audit (backend/data, quant, skills, experiments)

Audit only; no repo files modified except this report. Scratch scripts: `/tmp/claude-1000/-home-zeek-ML-financial-analyst-system/b051ea05-c261-4090-90ba-469e6c70ea6d/scratchpad/quant/t1.py`, `t2.py`, `t3.py`.

## Summary
1. TA-Lib indicator math is correct where emitted (RSI matches hand-computed Wilder RSI to 1e-13), but the snapshot labels are misleading: "MACD_12_26_9" is the histogram, `strength` is a meaningless `min(|value|/100,1)` (OBV, SMA and price-scale values all saturate at ~1.0), and 4 of 21 registered indicators are never computed.
2. The experiments runtime is causal in its features and applies a next-bar-open shift, but multi-ticker split indices are positional across a ticker-major frame (OOS windows are not time-ordered), a full-weight target never trades once costs are non-zero, and a missing bar values a held position at zero.
3. Data adapters carry provenance for prices but not for fundamentals, macro, or Upstox technical inputs; naive timestamps are interpreted in the host timezone; `M&M` and similar NSE symbols are rejected by the ticker regex.
4. The news pipeline dedupe uses a bag-of-words title similarity that merges materially different headlines (12% vs 21% profit); the quality scorer crashes on naive datetimes and rewards future-dated items; paywall detection is computed but never used; there is no retry or fallback on TinyFish failures and no flagging of injected article text.
5. Highest-value missing features: peer/sector benchmarks, corporate actions and earnings calendar, shareholding pattern, NSE holiday/session awareness, relative-strength vs NIFTY, and valuation bands. Upstox exposes several of these endpoints and the code fetches but discards them.

## Correctness score: 5.5 / 10
Justification: indicator math (RSI, ATR, NATR, SMA, BBANDS via TA-Lib) is sound and fails closed on bad OHLC input; hashing, replay, and dataset integrity in experiments are good. Points lost for: a ticker-parsing hole that excludes Nifty-50 names, silent unit and tz ambiguity (yfinance `debtToEquity` is a percent figure, naive timestamps), misleading indicator semantics and an unused registry, and an experiments simulator with a no-trade failure, zero-valuation on missing bars, and non time-ordered OOS splits (so "oos" labelled metrics are not what they claim for panels). There is no peer or benchmark context, so the "valuation" output is interpretation-free text.

Tests: `uv run pytest backend/tests -k "quant or data or indicator or fundamental or technical" --no-cov -q` gave 47 passed, 508 deselected, 2 warnings (a pandas "Discarding nonzero nanoseconds" warning from `technical_engine.py:63`).

## Positive observations
- RSI/ATR/NATR/SMA/BBANDS via TA-Lib match expectations; fail-closed OHLC validation; indicator unavailability handled via NaN to `available=False`; short series degrade to `partial`.
- Experiments: features are causal (`ewm(adjust=False, min_periods)`, per-ticker groupby), signals use close with a next-bar-open execution shift, hash-verified datasets, atomic writes, ledger is append-only. No centred windows or full-sample scalers found.
- Content-addressed provider archive with hash verification and strict replay; SSRF guard and byte cap in the extractor; Upstox quota is local and persisted.

## Unverified
- All yfinance live behaviours (NaN rows, `dividendYield` units, `debtToEquity` scale, `auto_adjust` default, news schema) were inferred from code and library knowledge; no network calls were made (0 of 5 used).
- Upstox adapter behaviours (candle ordering, adjustment status, timestamp format, `instruments/search` result shape) were not tested; no paid provider was called.
- DQ-24 (tool_runner period/provenance behaviour) is from code reading; that file belongs to another agent's scope and was read only for data fallback logic.
- Impact of DQ-03 on a fitted (non-EMA) strategy is by design analysis; the only strategy shipped is parameter-free.
- `NewsPipelineRecord` scoring crash (DQ-28) was shown for `QualityScorer.score` directly; whether upstream normalisation always supplies tz-aware times was not traced.
- TinyFish response schema and rate limits were not exercised.
- TA-Lib vs pandas-ta-classic consistency: only KC_20 and CMF_20 use pandas-ta-classic, taking `kc.iloc[:, 1]` as the middle band (column order not verified against the library version); their numerical correctness was not independently checked.
