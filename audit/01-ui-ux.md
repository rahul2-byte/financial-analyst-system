# FIN-AI UI/UX audit (01)

## Summary
1. The streaming Textual shell works for the happy path (progress, streamed markdown, sources, completion), and the event reducer and sanitizer are solid.
2. Most of the slash-command and session surface is advertised but not implemented: `/sessions`, `/resume`, `/context`, `/compact`, `/history`, `/retry`, `/mode` and Ctrl+K only echo the command (confirmed by running the app headlessly).
3. The chrome has fake or placeholder content: hardcoded "recent sessions", fake Attach/Web Search/Deep Research tools, an always-on "Online" badge, and Watchlist/Settings buttons that do nothing.
4. Non-interactive modes are weak: the Phoenix banner pollutes stdout and corrupts `--json`, one-shot output is buffered with no streaming, there is no citation list, and exit codes are always 0.
5. There is no export, copy, history search, watchlist, charts, NO_COLOR support or accessibility story, and no UI tests exist for `finai`.

## Current-state UX score: 4.5 / 10
The core loop (ask, watch stage and tool progress, read streamed markdown, see sources) is clean and has a sensible state machine, sanitization, cancel, queueing and an approval modal. That earns the baseline. Points are lost because discoverable features (sessions, resume, context, history, retry, mode) are dead, so the product misleads. Placeholder or fake UI erodes trust, which is costly for a finance tool. Header and footer are visibly broken at 80 columns. Scripting output is unsafe. Long-report handling is untuned, and top-tier features are missing.

## Top 5 changes for the biggest UX jump
1. Make the slash commands real (UX-01, UX-04): finish sessions/resume/history/retry/context/compact/mode and add unknown-command errors. This fixes a P0 trust problem.
2. Ship the session picker and resume flow (UX-02, UX-03, UX-23), with correct ordering, and rebuild the transcript on resume.
3. Remove fake chrome and fix the header (UX-08, UX-09, UX-10): delete mock sessions, fake tools and dead nav buttons, and add a real `?` help.
4. Make non-interactive output trustworthy (UX-05, UX-06, UX-07): clean stdout, streamed output, a citation list and exit codes.
5. Add export/copy and fix streaming performance and scrolling (UX-11, UX-14): `/export md`, `/copy`, throttled markdown updates, and smart auto-scroll.

## Unverified
- UX-12 root cause: I observed the stuck second run and the cross-run state bleed in a Pilot script using a fake event stream. I did not isolate whether it is the queued start inside the cancelled task or the shared `self.state`.
- No real research run or provider call was made (per rules), so true streaming latency, real approval payloads, clarification content and error text from the backend were not exercised.
- The approval modal, `SessionScreen` visuals and the Reports button were read from code and not screenshotted.
- UX-19: the contrast ratio was computed by hand, not with a tool. NO_COLOR behavior (UX-20) is from grep only. The Textual built-in `copy_text` action may exist in the installed Textual version (UX-13).
- The Phoenix banner (UX-05) appeared on stdout in my environment. Whether it appears depends on `FINAI_OBSERVABILITY_ENABLED`, which I did not read from `.env`.
- Terminal behavior of Shift+Enter was not tested in real terminals.
- Artifacts (not in repo): the pilot and cancel scripts and the screenshots are in `/tmp/claude-1000/-home-zeek-ML-financial-analyst-system/b051ea05-c261-4090-90ba-469e6c70ea6d/scratchpad/ui/`.
